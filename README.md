# Invoice Fraud Detection Using Machine Learning

## Overview
This project detects fraudulent invoices using Machine Learning techniques.  
The model analyzes invoice-related features and predicts whether an invoice is legitimate or fraudulent.

---

## Features
- Fraud prediction using ML
- Streamlit web application
- User-friendly interface
- Real-time prediction
- Trained ML classification model

---

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Model Information
- Algorithm Used: Random Forest Classifier
- Dataset Size: 10,000 entries
- Accuracy: 88%
